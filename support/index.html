Support

Seamen English Rules Pool

Having trouble aboard ship? This page covers the basics for Seamen English Rules Pool.

Contact

For support, bug reports or other enquiries, email: seamenpool@gmail.com

When reporting a problem, it helps to include your device model, Android version, what you were doing when the problem occurred, and any error message you saw.

Saving your progress

Game progress is stored locally on your device.

The game also includes save export and import features. Exporting creates a save file which you can keep somewhere safe and later import to restore your supported game progress.

It is a good idea to export a save before uninstalling the game, resetting your device or making other major changes.

Offline play

Seamen English Rules Pool is designed so that normal gameplay does not require a continuous internet connection once the game is installed.

Some external links, such as web pages or music services, naturally require an internet connection.

Troubleshooting

If the game behaves unexpectedly, first fully close it and open it again. If the problem continues, restarting the device may also help.

Before uninstalling the game as a troubleshooting step, export your save and make sure the exported file is safely stored.
